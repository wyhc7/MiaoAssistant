# 喵喵助手 (MiaoAssistant)

基于 Android **无障碍服务（Accessibility Service）** 的聊天文本改写工具，支持 **QQ / 抖音**。
在输入时自动按自定义规则改写文本：替换词语、句末追加语气词、附加随机颜文字。
> ⚠️ 微信 8.0.6x+ 已屏蔽第三方无障碍读取其界面，工具对微信暂不生效（详见下方已知限制）。

## 项目来源
本项目基于开源项目 [QiCaiJie114514/QQMiaoAssistant](https://github.com/QiCaiJie114514/QQMiaoAssistant)（QQ 无障碍文本改写助手）改进而来，
在其基础上新增了微信 / 抖音支持、内置默认规则、状态还原修复、屏蔽自检等特性，感谢原项目作者的思路与贡献。

## 功能
- **多应用支持**：QQ、抖音（含极速版）的输入框均可自动改写；微信受官方限制暂不可用
- **内置常用规则**：首次使用自动预置「我=本喵」「你=主人」「是=素」「什么=神马」「这样=酱紫」「喜欢=稀饭」，可自由修改或清空
- 自定义文本替换规则（`原词=替换词`，也支持 `＝` 全角等号 / `→`，多条按顺序应用）
- 断句追加（按标点分句，句末追加可自定义文本，默认"喵~"，输入波浪线 ~ 也会触发改写）
- 句末随机颜文字（内置 50+ 个，可自定义；实时模式下每条消息锁定同一枚，避免闪烁）
- 处理模式：标点触发 / 实时处理
- 全部配置本地持久化（`SharedPreferences`），仅作用于目标应用输入框

## 多应用适配说明
| 应用 | 包名 | 输入框定位 |
| --- | --- | --- |
| QQ / QQ国际版 | `com.tencent.mobileqq(i)` | 控件 ID `:id/input` |
| 微信 | `com.tencent.mm` | ⚠️ 8.0.6x+ 屏蔽第三方无障碍，暂不可用 |
| 抖音 | `com.ss.android.ugc.aweme` | 可编辑节点兜底 |

> 说明：微信与抖音的输入框控件 ID 随版本变化（混淆 ID），因此定位顺序为
> 「焦点可编辑节点 → 已知控件 ID → 第一个可编辑节点」，兼容大多数版本。
> 写入方式为 `ACTION_SET_TEXT`，不支持时自动回退「全选 + 剪贴板粘贴」（随后自动恢复原剪贴板）。
> 发送按钮除 ID 匹配外，还会按按钮文本「发送 / 發送 / Send」识别兜底。

### 已知限制
- 微信/抖音若使用**回车键直接发送**（不点击"发送"按钮），发送瞬间的兜底处理可能来不及写入，
  建议搭配**标点触发**模式使用（打字途中即完成改写）
- 部分深度定制 ROM 的无障碍行为可能有差异

## 工作原理
1. 无障碍服务监听目标应用的窗口切换、文本变化与点击事件
2. 检测到标点触发或实时模式下，读取输入框内容并维护"用户原文"
3. 经替换规则 → 断句追加 → 随机颜文字三级处理后写回输入框
4. 内置防循环机制：跳过自身写入产生的回显事件，避免无限改写

## 技术栈
- 纯 Android 原生 API（无第三方依赖）
- Java
- Gradle 8.8 / AGP 8.4.2
- minSdk 23 / compileSdk 34

## 构建
```bash
./gradlew assembleDebug    # debug 包，无需签名配置
./gradlew assembleRelease  # 正式签名包（需本地 keystore.properties）
```
产物：`app/build/outputs/apk/{debug,release}/`

### CI 自动构建
- **CI**：push 到 main / PR 时自动编译 debug APK 并上传 artifact
- **Release**：推送 `v*` 标签时自动构建 debug + 正式签名包，并附加到对应 GitHub Release

正式签名需在仓库 Secrets 中配置：`KEYSTORE_BASE64`、`STORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`；
本地签名则在项目根目录放置 `keystore.properties`（storeFile / storePassword / keyAlias / keyPassword），
密钥文件与 properties 均已 gitignore，切勿提交。

## 使用
1. 安装 APK（开启"允许未知来源"）
2. 打开应用 → 开启无障碍服务
3. 配置替换规则 / 断句 / 颜文字 → 保存设置（首次已预置常用规则）
4. 在 QQ / 抖音 的输入框中输入，触发规则自动改写
