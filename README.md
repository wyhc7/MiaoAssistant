# 喵喵助手 (MiaoAssistant)

基于 Android **无障碍服务（Accessibility Service）** 的聊天文本改写工具，支持 **QQ / 微信 / 抖音**。
在输入时自动按自定义规则改写文本：替换词语、句末追加语气词、附加随机颜文字。

## 功能
- **多应用支持**：QQ、微信、抖音（含极速版）的输入框均可自动改写
- **内置常用规则**：首次使用自动预置「我=本喵」「你=主人」「是=素」「什么=神马」「这样=酱紫」「喜欢=稀饭」，可自由修改或清空
- 自定义文本替换规则（`原词=替换词`，也支持 `＝` 全角等号 / `→`，多条按顺序应用）
- 断句追加（按标点分句，句末追加可自定义文本，默认"喵"）
- 句末随机颜文字（内置 50+ 个，可自定义）
- 处理模式：标点触发 / 实时处理
- 全部配置本地持久化（`SharedPreferences`），仅作用于目标应用输入框

## 多应用适配说明
| 应用 | 包名 | 输入框定位 |
| --- | --- | --- |
| QQ / QQ国际版 | `com.tencent.mobileqq(i)` | 控件 ID `:id/input` |
| 微信 | `com.tencent.mm` | 已知控件 ID + 可编辑节点兜底 |
| 抖音 / 极速版 | `com.ss.android.ugc.aweme(.lite)` | 可编辑节点兜底 |

> 说明：微信与抖音的输入框控件 ID 随版本变化（混淆 ID），因此优先尝试已知 ID，
> 找不到时自动回退为「查找第一个可编辑节点」，兼容大多数版本。
> 发送按钮除 ID 匹配外，还会按按钮文本「发送 / 發送 / Send」识别兜底。

## 工作原理
1. 无障碍服务监听目标应用的窗口切换、文本变化与点击事件
2. 检测到标点触发或实时模式下，读取输入框内容并维护"用户原文"
3. 经替换规则 → 断句追加 → 随机颜文字三级处理后写回输入框
4. 内置防循环机制：跳过自身写入产生的回显事件，避免无限改写

## 技术栈
- 纯 Android 原生 API（无第三方依赖）
- Java
- Gradle 8.8 / AGP 8.4.2
- minSdk 23 / compileSdk 34

## 构建
```bash
./gradlew assembleDebug
```
产物：`app/build/outputs/apk/debug/app-debug.apk`

## 使用
1. 安装 APK（开启"允许未知来源"）
2. 打开应用 → 开启无障碍服务
3. 配置替换规则 / 断句 / 颜文字 → 保存设置（首次已预置常用规则）
4. 在 QQ / 微信 / 抖音 的输入框中输入，触发规则自动改写
