# 喵喵助手 (MiaoAssistant)

基于 Android **无障碍服务（Accessibility Service）** 的聊天文本改写工具，支持 **QQ / 抖音 / 抖音极速版**。
在输入时自动按自定义规则改写文本：替换词语、句末追加语气词、附加随机颜文字，让聊天文案秒变「喵系」风格。

> ⚠️ 微信 8.0.6x+ 已屏蔽第三方无障碍服务读取其界面（即使关闭本工具，系统也无法获取其控件树），因此工具对微信**永久不可用**。详见下方「已知限制」。

## 功能特性

- **多应用支持**：QQ、QQ 国际版、抖音、抖音极速版的输入框均可自动改写；微信受官方限制暂不可用
- **主开关**：一键全局启用 / 停用，即时生效，无需关闭无障碍服务
- **内置常用规则**：首次使用自动预置「我=本喵」「你=主人」「是=素」「什么=神马」「这样=酱紫」「喜欢=稀饭」，可自由修改或清空
- **自定义替换规则**：`原词=替换词`（兼容全角 `＝` 与 `→`），多条按顺序依次应用
- **断句追加**：按标点分句，句末追加可自定义文本（默认 `喵~`）；输入波浪线 `~` / `～` 也会触发一次改写
- **随机颜文字**：内置 50+ 个，可自定义；实时模式下每条消息锁定同一枚，避免闪烁；并做了防重复处理，不会连续出现同一枚
- **处理模式**：标点触发 / 实时处理，可自由切换
- **语音输入修复**：语音整句插入（一次插入 ≥2 字）会立即改写，不再与「发送」动作竞态，避免了「发送后文本叠加重复」的问题
- **本地持久化**：全部配置保存在 `SharedPreferences`，仅作用于目标应用输入框
- **关于入口**：标题栏右上角 GitHub 图标可一键跳转本项目主页

## 支持的应⽤

| 应用 | 包名 | 输入框定位 | 状态 |
| --- | --- | --- | --- |
| QQ / QQ 国际版 | `com.tencent.mobileqq(i)` | 控件 ID `:id/input` | ✅ 可用 |
| 抖音 | `com.ss.android.ugc.aweme` | 可编辑节点兜底 | ✅ 可用 |
| 抖音极速版 | `com.ss.android.ugc.aweme.lite` | 可编辑节点兜底 | ✅ 可用 |
| 微信 | `com.tencent.mm` | — | ❌ 8.0.6x+ 屏蔽第三方无障碍，永久不可用 |

> 说明：抖音 / 抖音极速版的输入框控件 ID 随版本混淆变化，定位顺序为
> 「焦点可编辑节点 → 已知控件 ID → 第一个可编辑节点」，兼容大多数版本。
> 写入方式为 `ACTION_SET_TEXT`，不支持时自动回退「全选 + 剪贴板粘贴」（随后自动恢复原剪贴板）。
> 发送按钮除 ID 匹配外，还会按按钮文本「发送 / 發送 / Send」识别兜底。

## 使用说明

1. 从 [Releases](../../releases) 下载 APK 并安装（需开启「允许未知来源」）
2. 打开应用 → 开启无障碍服务（并打开主开关）
3. 配置替换规则 / 断句 / 颜文字 → 保存设置（首次已预置常用规则）
4. 在 QQ / 抖音 / 抖音极速版 的输入框中输入，规则即自动改写

## 工作原理

1. 无障碍服务监听目标应用的窗口切换、文本变化与点击事件
2. 在标点触发或实时模式下，读取输入框内容并维护「用户原文」
3. 经 **替换规则 → 断句追加 → 随机颜文字** 三级处理后写回输入框
4. 内置防循环机制：跳过自身写入产生的回显事件，避免无限改写；并对删除、整句插入等场景做了专门处理

## 已知限制

- **微信不可用**：微信 8.0.6x+ 在应用层直接屏蔽了第三方无障碍对其界面的读取（实测即使关闭本工具，`uiautomator dump` 仍返回空树，而拨号盘、QQ、抖音均正常）。此为微信官方行为，任何代码或权限都无法绕过。
- **回车直接发送**：若微信 / 抖音使用「回车键直接发送」（不点击「发送」按钮），发送瞬间的兜底处理可能来不及写入，建议搭配**标点触发**模式使用（打字途中即完成改写）。
- **深度定制 ROM**：部分定制系统（如 ColorOS）的无障碍行为与系统控件渲染存在差异，个别机型的滚动条等细节可能需要额外适配。

## 构建

```bash
./gradlew assembleDebug    # debug 包，无需签名配置
./gradlew assembleRelease  # 正式签名包（需本地 keystore.properties）
```

产物：`app/build/outputs/apk/{debug,release}/`

### CI 自动构建

- **CI**：push 到 `main` 或提交 PR 时自动编译 debug APK 并上传 artifact
- **Release**：推送 `v*` 标签时自动构建 debug + 正式签名包，并附加到对应的 GitHub Release

正式签名需在仓库 Secrets 中配置 `KEYSTORE_BASE64`、`STORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`；
本地签名则在项目根目录放置 `keystore.properties`（storeFile / storePassword / keyAlias / keyPassword），
密钥文件与 properties 均已 gitignore，切勿提交。
